Fritidshus Trebodar

Kodgenererad modell (modeller/trebodar). Klicka på en del för information. Hjulet för kameran mot punkten under pekaren, hur nära som helst och genom väggar; dra med vänster knapp för att vrida och med höger för att panorera, kring punkten där du tar tag; dubbelklick sätter rotationscentrum. Piltangenterna går genom huset (PgUp/PgDn upp och ned, Skift fortare). Högerklicka på en del, i trädet eller på ett material för att visa bara det eller tona ner resten; Esc avslutar. Mät kanter, avstånd och parallella kanter med knapparna uppe till höger (K, A, P).
